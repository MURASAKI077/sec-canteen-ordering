# 系统 ER 图说明

系统数据库包含三类核心实体：用户、菜品和订单。

`account` 表用于存储用户账号信息，主键为 `userId`；`dishes` 表用于存储菜品信息，主键为 `dishId`；`orders` 表用于记录用户的下单关系，包含 `userId` 和 `dishId` 两个字段。

实体关系如下：

- 一个用户可以对应多条订单记录，因此 `account` 与 `orders` 是一对多关系。
- 一个菜品可以出现在多条订单记录中，因此 `dishes` 与 `orders` 是一对多关系。
- `orders.userId` 外键指向 `account.userId`。
- `orders.dishId` 外键指向 `dishes.dishId`。

由于本项目遵循学长项目的数据库结构，`orders` 表不额外增加 `orderId`、订单状态、下单时间等字段，只作为用户和菜品之间的关联表使用。
